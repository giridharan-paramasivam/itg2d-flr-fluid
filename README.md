# itg2d-flr-fluid

Pseudospectral solver for 2D fluid ITG with FLR nonlinearities.

itg2d.py solves the system with laplacian viscosity.

itg2d_hyper_etdrk4.py solves the system with hyperviscosity using a etdrk4 scheme.

itg2d_PV_hyper_etdrk4.py solves the potential vorticity conserving version of the system with hyperiscosity using a etdrk4 scheme.
